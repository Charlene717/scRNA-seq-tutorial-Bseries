## 這個資料庫是什麼

富集分析是把「一串基因」翻譯成「生物學語言」的那一步，工具與基因集資料庫多到眼花。這個資料庫沿用《細胞標注參考庫》的架構，把 B13 會用到的資源統整成兩層：

- **`精選參考庫.md`**——16 個第一線資源（基因集資料庫、R 工具鏈、單細胞活性推斷、網頁工具四類），每個寫清楚「定位、版本規模、授權存取、適用條件、不適用情境、引用」。
- **`延伸參考庫.md`**——13 個延伸資源，各附「適用條件」：什麼情況值得跳出精選去用它。
- **`富集分析參考庫.xlsx`**——同內容表格版（精選／延伸／決策指引三個工作表）。

## 先記住四條鐵則（B 系列語彙）

1. **富集的輸入決定方法**（B13）：一串顯著 marker → ORA（超幾何）；完整排名的 DE 結果 → GSEA/fgsea（不要先切 p 值再丟 GSEA）；想給每顆細胞打分 → escape/AUCell/UCell；想推 TF/pathway「活性」→ decoupleR＋CollecTRI/PROGENy。
2. **統計單位往上游追**（B12）：富集結果的可信度取決於餵進去的 DE 排名——cell-level p 值灌水的 DE 做出來的富集一樣灌水；pseudobulk DE 才是進階題的標準輸入。
3. **背景基因集（universe）是最常見的隱形錯誤**：ORA 的背景要用「這份資料實際測到的基因」，不是全基因體——單細胞測不到的基因不該進背景。
4. **參數三件事照舊**：用了哪個資料庫哪個版本（MSigDB 2026.1？GO release 日期？）、哪個方法、哪個背景——寫進筆記，富集結果才可重現。

## 選庫決策樹（從你手上的東西出發）

```
你手上是什麼？
├─ 一串 cluster marker（顯著基因清單）
│   ├─ 快速探索 → 網頁工具：Enrichr／ShinyGO／g:Profiler（貼上即得）
│   └─ 可重現流程 → clusterProfiler::enricher + msigdbr（記得設 universe）
│
├─ 完整排名的 DE 結果（logFC 或 stat 排序）
│   └─ fgsea 或 clusterProfiler::GSEA；基因集首選 MSigDB Hallmark（50 個、低冗餘）
│       → GO 結果冗餘 → rrvgo/REVIGO 去冗餘（延伸）
│
├─ 想給「每顆細胞」打 signature 分數
│   └─ escape（ssGSEA/GSVA/AUCell/UCell 一站式）或 UCell/AUCell 單用
│       （這是打分不是檢定——結論要回到 cluster/病人層級統計）
│
├─ 想推「活性」而不是「表現」
│   ├─ TF 活性 → decoupleR + CollecTRI（1,186 TFs；官方已建議取代 DoRothEA）
│   ├─ Pathway 活性 → decoupleR + PROGENy（14 條 footprint pathways）
│   └─ Regulon 從頭推斷 → pySCENIC（注意維護現況，見精選 #14）
│
└─ 多個 cluster 的 marker lists 要一次比較
    └─ Metascape multi-list meta-analysis（延伸）

資料庫怎麼選？
├─ 第一輪永遠：MSigDB Hallmark（50）＋ GO BP
├─ 訊號/代謝機制 → Reactome（CC0 免費）＞ KEGG（授權三重限制，見精選 #5）
├─ 主題新、社群策展 → WikiPathways（CC0）
└─ 商用環境 → 避開 KEGG；用 Reactome/WikiPathways/STRING（CC BY）
```

## 維護注意（2026-09 查證時的現況快照）

- **MSigDB 已到 2026.1（35,361 sets）且新增 C9 collection**（computational perturbation signatures, 62 sets）——教材寫「C1–C8」的地方要更新；Hallmark = 50 不變；下載需免費註冊，msigdbr 套件可免註冊取用。
- **KEGG 三重限制**：FTP 大量下載採訂閱制、REST API 限學術（≤3 請求/秒）、商用需購買授權；clusterProfiler 的 enrichKEGG 執行時連網抓資料。商用環境改用 Reactome（CC0）/WikiPathways（CC0）。
- **DisGeNET 已商業化**（disgenet.com）：免費層需學術申請，批量下載不再開放——舊筆記的「免費下載全庫」已不成立。
- **DoRothEA 官方已建議改用 CollecTRI**；**SCENIC R 版官方棄用**（用 pySCENIC，但其最新 release 停在 2022，新專案可看 SCENIC+）。
- **decoupleR 重心已移到 Python 版**（decoupler 2.2.0, scverse）；R 版（Bioconductor 2.17.0）仍可用但長期維護狀態不明。
- **ShinyGO 已到 0.86**（2026-08，Ensembl 115）；DAVID Knowledgebase v2025_2 仍維護但資料快照較舊。
- 本庫查證日期 2026-09-07；引用前開官方頁確認版本，並在報告記下資料庫版本與取用日期（鐵則 4）。
