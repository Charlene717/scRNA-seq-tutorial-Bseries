## 這個資料庫是什麼

細胞標注（cell type annotation）是單細胞分析中最吃「外部知識」的一步：你需要 marker 基因字典、參考圖譜、自動標注工具，還有腫瘤情境下的惡性判定與細胞狀態程式。這個資料庫把課程與題庫會用到的標注資源統整成兩層：

- **`精選參考庫.md`**——16 個第一線資源，每個都寫清楚「定位、規模、存取、適用條件、不適用情境、怎麼用、引用」。日常分析從這裡選就夠。
- **`延伸參考庫.md`**——20 個延伸資源，各附「適用條件」：什麼情況值得跳出精選去用它（跨物種、特殊組織、蛋白質佐證、歷史工具……）。
- **`細胞標注參考庫.xlsx`**——同內容表格版（精選／延伸／決策指引三個工作表），方便快速篩選。

## 先記住三條鐵則（B 系列語彙）

1. **自動標注是假設，不是答案**（B10）：任何工具吐出的標籤都要用 marker 圖（DotPlot/FeaturePlot）回頭驗證，並在筆記記下「工具、參考集、版本、日期」四件事——參考庫會更新，你的紀錄是唯一能重現的東西。
2. **惡性判定靠 CNV，不是 marker**（B16）：腫瘤樣本先走 CNV 推斷（inferCNV/CopyKAT）搭配跨病人分群行為，再談細胞型別；marker 只能標微環境。
3. **參考集的本質決定它的極限**：celldex 那批是「bulk 純化族群」——大類穩、連續狀態與罕見型別弱；圖譜映射（Azimuth/HLCA）只認得參考裡有的型別——疾病特有狀態會被硬塞到最近的健康標籤（進階30 的核心教訓）。

## 選庫決策樹（從你的資料出發）

```
你的資料是什麼物種？
├─ 人或小鼠 → 往下走
└─ 其他物種 → 延伸庫：Cell Taxonomy（34 物種）、EBI SCEA（21 物種）；
              多半要自建 marker 清單（找該領域圖譜論文附表）

樣本含腫瘤嗎？
├─ 是 → 先做惡性判定（精選：inferCNV/CopyKAT/scATOMIC 三件套，注意各自失效癌種）
│       惡性細胞 → 3CA meta-programs／Gavish Table S2 做狀態註解
│       微環境細胞 → 當正常組織走下面的流程
└─ 否 → 往下走

組織在 Azimuth 官方 15 個 reference 清單內嗎？（PBMC/骨髓/肺/腎/胰/心/肝/脂肪/扁桃腺/皮質…）
├─ 是 → Azimuth 網頁版或 RunAzimuth() 先跑一輪當第一意見
└─ 否 → 腦組織 → Allen Brain Cell Atlas（延伸）
        其他組織 → CELLxGENE 找該組織圖譜（h5ad）自建參考

你的流程是 R 還是 Python？
├─ R → SingleR + celldex（挑對參考集：PBMC 用 MonacoImmune、造血用 Novershtern、
│      小鼠免疫用 ImmGen、小鼠泛用 MouseRNAseq）＋ scType 快速第二意見
└─ Python → CellTypist（77 個模型；免疫用 Immune_All_Low 起手）

最後一律：手動 marker 驗證
└─ CellMarker（查文獻級 marker）＋ HPA single cell（蛋白質層級佐證，延伸）
   ＋ UCSC Cell Browser（看同類研究的作者原始註解，延伸）
```

## 維護注意（2026-09 查證時的現況快照）

- **inferCNV 官方已宣告停止支援**（README 明文，點名替代品 inferCNA/CopyKAT/Numbat），但 Bioconductor 3.21 仍收錄 v1.24.0 可正常安裝——教學仍用它示範，正式研究建議加測替代品。
- **CellMarker 主站已升 3.0**，2.0 的下載頁 404；引用規模數字時標明出自 2.0 論文（NAR 2023）。
- **PanglaoDB 實質停更**（marker 表停在 2020-03-27）——教學輕量好用，正式研究要搭新資料庫。
- **CELLxGENE 的 rds/Seurat 下載在棄用中**，長期以 h5ad/Census 為主——R 使用者記得練 h5ad 轉檔（基礎20）。
- 舊網址轉址：portal.brain-map.org→brain-map.org；immunesinglecell.org→disco.bii.a-star.edu.sg；TISCH 用 tisch.compbio.cn。
- 本庫查證日期為 2026-09-07；資源規模與網址會變動，引用前花 30 秒開官方頁確認版本，並在報告記下取用日期。
