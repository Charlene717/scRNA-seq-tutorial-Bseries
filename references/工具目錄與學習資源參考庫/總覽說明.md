## 這個資料庫是什麼

這是四庫體系的最後一塊。前三庫回答「去哪找資料」「怎麼標細胞」「怎麼解讀基因清單」；這一庫回答更上游的兩個問題：**「做 X 分析該用什麼工具」**與**「去哪學」**。單細胞工具已超過 1,800 個，學生最缺的不是工具，是選工具的方法。

- **`精選參考庫.md`**——12 個第一線資源（工具目錄、線上書與官方教學、課程訓練、方法選擇證據四類）。
- **`延伸參考庫.md`**——7 個延伸資源，各附「適用條件」。
- **`工具目錄與學習資源參考庫.xlsx`**——同內容表格版（精選／延伸／決策指引）。

## 先記住三條鐵則（B 系列語彙）

1. **選工具走四步**：目錄找候選（scRNA-tools／awesome-single-cell）→ benchmark 找證據（Open Problems／scIB／sc-best-practices 各章）→ 官方教學確認自己跑得動（Seurat/Scanpy vignettes）→ **記下工具與版本**（參數三件事的工具版）。跳過中間兩步直接抄最新工具，是踩雷區的常客。
2. **目錄收錄 ≠ 推薦**：scRNA-tools 收 1,847 個工具，其中大量已停止維護——收錄只代表「存在過」。判斷可不可用看三件事：最後 commit 日期、是否進 Bioconductor/CRAN/PyPI 正式發布、有沒有 benchmark 論文背書。
3. **R 和 Python 是兩套對應的生態，不是兩個世界**（B18）：R 側 Seurat＋Bioconductor（OSCA 是教科書）；Python 側 scverse（sc-best-practices 是教科書）。每個任務兩邊都有對應工具——本庫精選表把對應關係列清楚，跨生態交接照 B18 的驗收原則。

## 選庫決策樹（從你的問題出發）

```
「做 X 該用什麼工具？」
├─ 先查課程：B 系列對應集數已經教了一個 → 先用課程教的，能動再談換
├─ 課程沒教的任務 → scRNA-tools 按 category 找候選（注意 low-maintenance 警語）
│   → awesome-single-cell 補新工具 → 有沒有 benchmark？
│       ├─ 整合方法 → scIB（Nat Methods 2022）
│       ├─ 其他常見任務 → Open Problems 排行榜（13 個任務、125 個方法）
│       └─ 教科書級建議 → sc-best-practices 對應章節（附文獻論據）
└─ 空間工具 → Museum of Spatial Transcriptomics（1,098 個工具，延伸庫）

「去哪學 Y？」
├─ R 路線 → OSCA 五冊（搭 Seurat vignettes 動手）
├─ Python 路線 → sc-best-practices（搭 Scanpy tutorials 動手）
├─ 不會寫程式先體驗流程 → Galaxy Training（網頁免安裝）
├─ 找可改作的授課教材 → HBC training（CC BY 4.0）
└─ 10x 資料的實務細節 → 10x Analysis Guides（延伸）

「這個工具還活著嗎？」
└─ GitHub 最後 commit ＋ 正式發布管道 ＋ benchmark 背書，三者至少要有二
```
