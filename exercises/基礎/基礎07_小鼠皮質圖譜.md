# 基礎 07 · 換物種也換組織：小鼠皮質圖譜

**難度**：★ ｜ **預估時間**：0.5–1 個工作天 ｜ **對應集數**：B5–B10

## 背景與研究主題

Zeisel 等人（2015）用 Fluidigm C1 對小鼠體感皮質與海馬 CA1 定序了 3,005 顆細胞，是單細胞領域最早的「無偏見組織圖譜」之一。這一題你要同時換兩樣東西：**換物種**（小鼠基因名首字大寫，SNAP25 變 Snap25，粒線體前綴變 `mt-`）與**換組織**（腦組織的 marker 課程沒餵過，得自己查）。腦的另一個特點是註解有**層次**：先分神經元 vs 膠細胞，再把神經元拆成興奮性（pyramidal）與抑制性（interneuron），interneuron 底下還有次分類——一層一層來，正是 B9「先大後小」與 B10 註解工作流程的合體練習。你的研究主題：

1. 皮質/海馬組織有哪些大類細胞？神經元、星狀膠、寡樹突膠、微膠、血管細胞分得開嗎？
2. 神經元大群裡，興奮性與抑制性神經元怎麼區分？interneuron 能再拆出次群嗎？
3. 你的分群與原論文的兩層註解（大類 vs 次類）對得上多少？差在哪一層？

## 資料集

- **GSE60361**（Zeisel；STRT/C1 平台，Fluidigm，含 UMI）。小鼠皮質＋海馬 CA1，3,005 cells。
- 下載：GEO accession 頁 Supplementary files 的 **txt matrix**（`C1-3005-Expression.txt.gz`）。
- 格式注意：這個 txt 不是乾淨的基因×細胞矩陣——表頭夾了多列細胞 metadata（含組織來源、性別等欄位，以及作者的 **level1class／level2class 註解**，那是你「對答案」的鑰匙）。先 `readLines(n = 15)` 看清楚結構再決定怎麼讀，metadata 列抽出來存好，矩陣主體才餵 Seurat；以你實際看到的檔案結構為準。

## 任務

### 階段 A：讀入與標準流程（對應 B5–B9）

1. 解剖 txt 結構：把 metadata 列（含 level1class/level2class）與表達矩陣分開，建 Seurat 物件並用 `AddMetaData()` 把作者註解掛上（階段 B 第 6 步之前假裝沒看到）。用 `dim()` 確認細胞數與基因數合理。
2. 小鼠 QC：`PercentageFeatureSet(obj, pattern = "^mt-")`——注意大小寫；若抓到 0 個基因，先 `grep("^mt", rownames(obj), value = TRUE, ignore.case = TRUE)` 看這份資料的粒線體基因長什麼樣。C1 是微流體板材平台，nCount/nFeature 分布跟 10x 液滴很不一樣，閾值照舊「數字、理由、紀錄」三件事。
3. 標準流程到 UMAP＋分群（參數三件事照基礎01 的標準）。

### 階段 B：腦組織的層次註解（對應 B10）

4. 先查 marker 再動手（來源記進筆記）。起點：泛神經元 Snap25、興奮性/pyramidal Slc17a7、抑制性/interneuron Gad1/Gad2、星狀膠 Aqp4、寡樹突膠 Plp1/Mbp、OPC Pdgfra、微膠 Cx3cr1/C1qb、內皮 Cldn5、mural/室管膜等其餘血管與支持細胞請自行查（CellMarker、PanglaoDB——注意選小鼠條目）。
5. 逐群註解出「大類」層級：註解後 UMAP＋「cluster × 型別 × 證據 marker」對照表。註解不出來的群誠實標 unknown。
6. 對答案第一層：你的大類註解 vs 作者 level1class 做交叉表（`table()`），逐格檢討不一致——是你錯、粒度不同、還是 resolution 問題？

### 階段 C：先大後小——拆神經元（對應 B9、B10）

7. `subset()` 出神經元大群重新跑 HVG→PCA→分群（B9 的「先大後小」：換了細胞子集，HVG 與 PC 都要重算，想清楚為什麼）。先分興奮性 vs 抑制性，再看 interneuron 能不能拆出次群（查 Pvalb、Sst、Vip 等經典 interneuron marker）。
8. 對答案第二層：子集分群 vs 作者 level2class 交叉表。寫 150–300 字筆記：哪一層你對得好、哪一層對不上？次類對不上時，是細胞數太少、深度不夠、還是你的 resolution 策略問題？

## 繳交物

1. 可重跑的 R 專案（含 txt 解剖與讀入程式碼）。
2. 圖：QC 分布、大類註解 UMAP、marker DotPlot、神經元子集重分群 UMAP（英文標籤）。
3. 分析筆記：參數三件事＋marker 查證來源＋兩層交叉表檢討。
4. 層次註解筆記（150–300 字）。

## 提示（卡關再看）

<details><summary>提示 1：txt 解剖</summary>
`readLines("C1-3005-Expression.txt", n = 15)` 先看前幾列各是什麼；metadata 列通常在基因列之前。可以整檔讀成 data.frame 後按列名把 metadata 抽走，剩餘部分轉 matrix；細胞 ID 與 level1class/level2class 存成獨立 data.frame，順序要跟矩陣欄位對齊（用 ID 對，不要靠位置賭）。
</details>

<details><summary>提示 2：找不到 marker 或 marker 不亮</summary>
最常見死因是大小寫：小鼠是 Snap25 不是 SNAP25。`grep("snap25", rownames(obj), ignore.case = TRUE, value = TRUE)` 一查便知。查資料庫時務必選 Mus musculus 條目——人鼠同源基因大多同名，但不是全部。
</details>

<details><summary>提示 3：interneuron 拆不開</summary>
interneuron 細胞數少，在全資料的 resolution 下常被壓成一群。子集重分群後調高 resolution，逐一看 Pvalb/Sst/Vip 的 FeaturePlot；若還是拆不開，看每群細胞數——3,005 顆的資料裡次類可能只有幾十顆，「拆不出來」本身就是可以寫進筆記的誠實答案。
</details>

## 進階挑戰

- 皮質 vs 海馬 CA1 兩個組織來源（metadata 有）分開看：哪些型別是共用的、哪些有組織特異性？pyramidal 細胞在兩個區域是同一群嗎？
- 用 Allen Brain Atlas 的 in situ 資料庫抽查 2–3 個你自己選定的次類 marker 的空間表現，體驗「跨資料型態驗證註解」。
- 腦組織的註解功力到了進階25（阿茲海默 snRNA-seq，人類 entorhinal cortex）會直接派上用場——同一套膠細胞 marker，換成人類大寫再戰一次。
