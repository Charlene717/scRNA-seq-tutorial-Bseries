# B 系列 · 實作練習題庫

**配套**：B 系列 · 實作篇 19 集（`../slides/`）與隨集腳本（`../R/`）
**定位**：看完課程之後的「自己動手」關卡，分兩層。**基礎題**（20 題）把標準流程、常見資料型態與核心技能練熟；**進階題**（60 題，60 個各不相同的公開資料來源）教你面對真實數據——格式陷阱、決策日誌、發表導向的階段設計，最理想的情況是分析結果真的長出可投稿的新生物意義。

## 資料夾結構

- `基礎/基礎NN_*.md` —— 20 張基礎題卡
- `進階/進階NN_*.md` —— 60 張進階題卡
- `進階/_從練習到投稿指南.md` —— 所有進階題共用的發表指南（再分析的正當切入點、投稿最低標準、期刊層級）
- `資料集總覽.md` / `.xlsx` —— 全部資料集的 accession、規模、格式、下載方式（涵蓋 GEO、10x、SeuratData、cellxgene、Broad SCP、Dryad、官方圖譜站等來源）
- 細胞標注做任何題之前，先看 **`../references/細胞標注參考庫/`**（總覽說明＋精選 16／延伸 20 個標注資源、選庫決策樹、xlsx 目錄）——所有需要 marker 庫、參考圖譜、自動標注工具或惡性判定資源的題目都從那裡選庫。
- 富集分析（B13 相關任務）同樣先看 **`../references/富集分析參考庫/`**（總覽說明＋精選 16／延伸 13 個資源：基因集資料庫、GSEA/ORA 工具、單細胞活性推斷，含 KEGG 授權與 universe 設定等踩雷提醒）。
- 要找題庫以外的「新」資料（scRNA 或空間轉錄組）時，看 **`../references/單細胞與空間資料庫參考庫/`**（精選 16／延伸 11 個資料入口：GEO/CELLxGENE/圖譜站、空間資料庫、accession 型別對照與 raw vs processed 層級鐵則）——資料集總覽收的是具體題目資料集，那裡收的是入口。
- 題卡要你「寫工具選擇理由」或想自學補課時，看 **`../references/工具目錄與學習資源參考庫/`**（精選 12／延伸 7：scRNA-tools/scverse 等工具目錄、OSCA/sc-best-practices 線上書、Open Problems/scIB 等 benchmark 證據，含「選工具四步」鐵則）。

## 使用方式

1. 題目卡結構:基礎卡十節（背景 → 資料集 → 任務 A/B/C → 繳交物 → 自我檢核點 → 提示 → 進階挑戰 → 文獻）；進階卡多兩節——**真實數據關卡**（讀檔前的格式解剖、尺度確認、決策日誌 `decisions.md`）與**發表路徑**（訊號分類、驗證設計、novelty 查證、目標期刊層級）。
2. 通用規範（全部題目適用）：
   - `set.seed(1234)`；專案用 RStudio Project + renv；相對路徑，不寫 `setwd()` 絕對路徑。
   - 每一個自訂參數（QC 閾值、resolution、nPC…）要能答出「數字、理由、紀錄」三件事（B 系列鐵則）。
   - 繳交的圖使用英文標籤（投稿習慣）；分析筆記中文即可。
   - 涉及腫瘤資料時，先回想該步驟的「⑤+ 策略室」內容再動手。
3. 進階題的階段 C 一律是發表導向：找原論文沒問過的問題、用新方法重審、或跨資料集組合。做完先讀 `進階/_從練習到投稿指南.md` 再寫發表路徑評估。

## 建議路線

- **基礎**：第一圈選 3–4 題（必含 01）→ 第二圈選 4–6 題（10、11 必做）。
- **進階入門三部曲**：01 → 02 或 03 → 挑主線。
- **主線任選**（每條 3–5 題）：惡性判定線 01→03→12→37；發育起源線 21→36→44（前置 04/15）；微環境/通訊線 04→06→08→50→26；大隊列驗證線 11→18→24→10；配對設計線 39→45→51→52；非腫瘤疾病線 47→48→49→53；新模態線 60→29→40 或 28→30→58；因果線 59（獨立）。
- 全學程約 60–90 個完整工作天；課程設計建議每學期 1 條基礎圈＋1–2 條進階主線。

## 給助教／出題者

- 「自我檢核點」可直接當批改 rubric；進階題另可用 `decisions.md` 決策日誌評「面對真實數據的判斷力」。
- 參考答案刻意不附：題卡的「自我檢核點」就是判斷做對沒有的依據。
- 資料集連結若失效，優先到 GEO accession 頁面找 supplementary files；10x 資料到 10x Datasets 頁搜尋；其他來源見資料集總覽「下載注意事項」。
