# 進階 37 · CNV 訊號弱的時候：兒童 ALL 對答案

**難度**：★★★ ｜ **預估時間**：2 個工作天 ｜ **對應集數**：B10、B11、B16、B19（血癌戰法）｜ **資料集**：GSE132509（本題獨用）

## 背景與研究主題

兒童急性淋巴性白血病（ALL）的惡性 blast 是 B 前驅細胞的惡性版本——marker 幾乎全部與正常 B 系發育階段重疊，這是進階05 AML 邏輯的翻版。但 ALL 給惡性判定加了一道新難題：不少亞型的 CNV 訊號很弱（融合基因驅動的腫瘤染色體可以近乎平整），「惡性判定靠 CNV 不是 marker」這句話在這裡會被逼到極限——好在資料裡藏著一個正對照：高倍體（high hyperdiploid, HHD）亞型是「整條染色體多一份」的教科書級 aneuploidy，inferCNV 理應看得一清二楚。Caron 等人（2020）的資料附有 **cell_annotations.tsv（含作者型別註解與 UMAP 座標）**——這讓本題像進階03 一樣有標準答案可對。你的研究主題：

1. 不靠作者答案，B 系 blast 與正常 B 系/其他細胞分得出來嗎？CNV、病人限定性、與健康對照的分離——三路證據各說什麼？
2. CNV 訊號在不同 ALL 亞型間（各病人的診斷亞型以 GEO 頁為準）強弱差多少？HHD 病人真的是你的 inferCNV 正對照嗎？CNV 弱的病人，你的判定退守到哪些證據？
3. 健康兒童對照與病人樣本的組織來源一樣嗎？這個混淆讓哪些「病人 vs 健康」比較從設計上就不能做？

## 資料集

- **GSE132509**（10x 3'；~46,211 cells：39,375 ALL 骨髓單核細胞／8 位病人 + 6,836 健康兒童細胞；健康樣本數、各病人診斷亞型與組織來源以 GEO 頁為準）
- 格式：**RAW.tar（逐樣本 10x MTX）+ cell_annotations.tsv.gz**，GEO Supplementary files 下載。
- 註解檔是「對答案」用的——讀入時先蓋住（見真實數據關卡 2），不是分析起點。

## 真實數據關卡

真實資料在你跑第一行 Seurat 之前就開始出題。照做並記錄：

1. **RAW.tar 的 10x 三件套批次讀入**：解 tar 後盤點檔案組織方式（每樣本一個資料夾？還是攤平、靠檔名前綴區分？以實際為準）。`Read10X` 認的是標準檔名（matrix.mtx／barcodes.tsv／features.tsv 或 genes.tsv），不合就寫腳本改名分資料夾（進階15 的同款功課）；迴圈讀入、`add.cell.ids` 加樣本前綴，每樣本細胞數對帳。
2. **cell_annotations.tsv 先蓋住**：作者的型別註解與 UMAP 座標欄**讀入後全部改名加 `author_` 前綴收起來，自己判定完成前不准看**（理由同進階05——看過答案的判定不是獨立判定）。同時做兩件對帳：註解檔的 barcode 規則與你合併後的細胞名對得起來嗎（前綴、後綴 -1）？註解檔行數與矩陣細胞總數差多少（差的細胞是誰砍的——作者 QC？）？
3. **樣本 metadata 與組織混淆**：從 GEO 樣本頁解析每位病人的診斷亞型（ETV6-RUNX1？HHD？以 GEO 頁為準）與每個樣本的組織來源。**健康兒童對照的取樣組織與病人是否相同，自查 GEO 樣本描述**——若不同（例如健康是周邊血系材料、病人是骨髓），那麼任何「病人 vs 健康」差異都疊著組織差異，這是 B11 整合範圍與統計混淆的實戰教材：混淆寫進 decisions.md，並在後面每個比較裡回應它。
4. **決策日誌**：開 `decisions.md`，凡是「資料逼你做的決定」都記一筆：發現了什麼 → 選項 → 你選了什麼 → 理由。它是繳交物，也是論文 Methods 的草稿。

## 任務

### 階段 A：讀入、QC 與整合決策（B5–B11）

1. 批次讀入全部樣本、QC（閾值看分布訂，⑤+ 策略室過一遍）到 UMAP。
2. 整合決策：健康 vs 病人、樣本之間——不整合／只在健康樣本內整合／全整合三條路，各會把什麼訊號當 batch 抹掉？（提醒：惡性細胞病人特異是生物訊號，被整合「修好」是災難。）選路、理由、事後檢查，進 decisions.md。
3. 註解主要族群：T/NK、myeloid、erythroid、B 系（此刻先不分惡性）——只用 marker，不碰 `author_` 欄。

### 階段 B：三路證據判惡性（B16、B19 血癌戰法）

4. 正常 B 系參照：健康對照的 B 系細胞按發育階段註解（pro-B/pre-B/immature/naive 等 marker 自查文獻）；病人的 B 系細胞與這個參照比對（label transfer 或共嵌入後看分離度）——「像正常哪一站、像的程度」量化。
5. inferCNV：各病人樣本內的 T/NK 當 reference。先寫預測再跑：HHD 病人應出現整條染色體級的增益（正對照）；其他亞型呢？跑完對答案：正對照成立嗎？CNV 弱的病人有哪些？
6. 三路交叉給每顆 B 系細胞判定（惡性/正常/不確定）：(a) CNV；(b) 病人限定性——正常細胞跨病人混居、惡性細胞病人特異（B19 血癌戰法的老朋友）；(c) 與正常 B 系參照的偏離。三路一致性比較（upset 圖或混淆表），只有一路支持的細胞是誰。

### 階段 C：揭曉對答案（發表導向）

7. 揭開 `author_` 欄：你的判定 × 作者註解混淆矩陣；分歧細胞集中在哪些病人、哪個 B 系發育位置？把作者的 UMAP 座標畫出來與你的 UMAP 並排——同一批細胞、兩套流程，結構差在哪？
8. 深挖一個分歧區塊或被忽略的角落（例如病人骨髓裡的正常殘餘造血——它們是天然的「病人內對照」，作者用了嗎？）；穩健性：換 resolution、換整合路線、去掉細胞數最多的病人重跑。
9. 寫「發表路徑」評估（見下節）。

## 繳交物

1. 可重跑的 R 專案（renv + `set.seed(1234)`、相對路徑、含讀入與改名腳本）＋ `decisions.md` 決策日誌（含蓋住的欄位清單、組織混淆、整合決策）。
2. 圖：註解 UMAP、inferCNV 熱圖（HHD 正對照標明）、三路判定一致性圖、與作者對答案混淆矩陣＋雙 UMAP 並排、階段 C 深挖圖組（英文標籤）。
3. 分析筆記：參數三件事＋各階段回答。
4. 發表路徑評估（300–500 字）。

## 發表路徑

讀 `_從練習到投稿指南.md` 後回答：

- **訊號分類與穩健性**：你的訊號（CNV 弱時的判定策略？分歧的系統性規律？）屬於指南第二節哪一類？病人層級只有 8 個點——哪些結論的統計單位撐得住？
- **驗證設計**：方法那半邊的現成交叉檢查場是**進階05 的 GSE116256**——AML 的「正常參照系＋三路偏離量化」與你這裡的三路證據同構，把兩題的分歧規律並排就是一個方法學故事的雛形；時序/亞群動態的對照可看**進階20 的 GSE111014**（另一血癌、治療多時點）。ALL 專屬的獨立驗證資料集自己上 GEO 查（關鍵字「pediatric ALL scRNA-seq」，規模與格式以 GEO 頁為準），查到什麼寫進評估。
- **novelty 定位**：ALL 的單細胞惡性判定與正常 B 系對照已有文獻（PubMed 查「acute lymphoblastic leukemia single-cell blast normal B progenitor」）——你的角度（CNV 強弱按亞型分層的系統比較？病人內正常殘餘當對照的用法？）查完還剩多少新？
- **缺什麼＋目標期刊層級**：缺獨立 ALL 隊列與更多亞型覆蓋；組織混淆讓「病人 vs 健康」那條線先天跛腳，誠實寫進 Limitations。方法比較路線補齊 benchmark 可往 Briefings in Bioinformatics 層級；否則落點是 Scientific Reports 層級或先掛 bioRxiv。

## 提示（卡關再看）

<details><summary>提示 1：RAW.tar 改名分資料夾</summary>
攤平的 10x 檔通常長成 `GSMxxxxxxx_樣本名_matrix.mtx.gz` 這類。腳本裡對每個樣本 `dir.create()` 後把三件套改名成標準檔名搬進去，再 `Read10X(資料夾)`。改名對照表印出來存檔——這也是 decisions.md 的素材。
</details>

<details><summary>提示 2：病人限定性當證據</summary>
對每個 B 系分群算「病人組成熵」或最大病人佔比：正常 B 系群應該多病人混居（若你沒把它整合壞），佔比 >90% 的單一病人群是 blast 嫌疑犯。注意這個證據在「只有一位病人有某正常稀有型別」時會誤判——所以它只是三路之一。
</details>

<details><summary>提示 3：對答案的正確姿勢</summary>
混淆矩陣不是給你「準確率」自我安慰用的——把分歧細胞拉出來，按病人 × 作者標籤 × 你的標籤三維拆解，通常會發現分歧集中在一兩個病人的特定發育位置；那裡就是你階段 C 深挖的礦。
</details>

## 進階挑戰
