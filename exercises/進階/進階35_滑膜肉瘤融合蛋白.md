# 進階 35 · 一個駕駛、滿車乘客：滑膜肉瘤與融合蛋白

**難度**：★★★ ｜ **預估時間**：2 個工作天 ｜ **對應集數**：B11、B12、B16、B19 ｜ **資料集**：GSE131309（本題獨用）

## 背景與研究主題

多數成人癌是幾十個突變合力開車；滑膜肉瘤（synovial sarcoma, SyS）只有一個駕駛——**SS18-SSX 融合蛋白**，一次染色體易位把兩個染色質調控者焊在一起，整個腫瘤從此姓它。單一驅動事件的癌是絕佳的思想實驗場：既然大家的駕駛都一樣，惡性細胞的**表達多樣性從哪來**？Jerby-Arnon 等人（2021）的資料集（16,872 cells；12 個 SyS 腫瘤）還多給一層方法學禮物：**Smart-seq2 與 10x 雙平台**——少而深、多而淺（進階09 的主題在腫瘤場景重演），而且這次兩個平台測的是同一批腫瘤。你的研究主題：

1. 同一個駕駛之下，12 顆腫瘤的惡性細胞有沒有共同核心程式？病人間還剩多少多樣性？
2. 雙平台各自看到什麼：哪些程式兩邊都穩、哪些只有深測（SS2）看得見、哪些要靠 10x 的細胞數才站得住？
3. 融合蛋白驅動的癌 CNV 負擔偏低——慣用的「惡性判定靠 CNV」在這裡還好使嗎？極限在哪？

## 資料集

- **GSE131309**（Smart-seq2 + 10x 雙平台；16,872 cells；12 個 SyS 腫瘤）
- 下載：GEO Supplementary files 的 **RAW.tar（762 MB，內為 CSV）＋ README**——**先讀 README**（GEO 資料集附 README 是罕見的福利，作者告訴你檔案怎麼組織，別跳過）。raw 定序資料為 DUOS 管制，不用去申請。
- CSV 的命名編了樣本與平台身分——哪些檔是 SS2、哪些是 10x、細胞數各多少，以 README 與 GEO 頁為準。
- 兩平台的尺度幾乎必然不同（SS2 無 UMI；10x 是 UMI counts）——每個平台各自確認，不能互抄。

## 真實數據關卡

真實資料在你跑第一行 Seurat 之前就開始出題。照做並記錄：

1. **README 優先＋RAW.tar 命名解剖**：`untar(..., list=TRUE)` 列出內容物、對照 README 建「檔名 → 樣本 → 平台 → 內容物」對應表。哪些是表達矩陣、哪些是註解或輔助檔？兩平台各覆蓋哪些腫瘤（重疊嗎）？表建好之前不准動手讀矩陣。
2. **兩平台各自的尺度確認**：各挑一個檔 `fread(nrows=5)` 看結構，數值分布判尺度——SS2 那批是 counts 還是 TPM/log 系（讀 README 與原論文 Methods，數值佐證）？10x 那批是整數 UMI 嗎？兩平台的正規化路線**分開決策**、分開寫進參數三件事。
3. **雙平台不硬整合**：先寫下處理架構再動工——本題的正解是**分開處理、程式層對照**，不是塞進同一次整合把平台差異「校正」掉（校正掉的可能正是你要研究的深淺差異；B11 整合範圍的決策這次答案是「不整合」，理由要能說出口）。真要做共同嵌入，放進階挑戰。
4. **決策日誌**：開 `decisions.md`，凡是「資料逼你做的決定」（對應表、兩套尺度、不整合的架構）都記一筆：發現了什麼 → 選項 → 你選了什麼 → 理由。這是繳交物，也是論文 Methods 的草稿。

## 任務

### 階段 A：兩條生產線（B11、B16）

1. 完成真實數據關卡，SS2 與 10x 各建一條處理線：各自 QC（plate 資料與 droplet 資料的 QC 分布完全不同——各訂各的閾值）、正規化、分群、大類註解。
2. 惡性判定靠 CNV 不是 marker——但本題要加一句誠實的但書：SyS 基因體相對安靜，inferCNV 的訊號可能微弱。免疫/基質當 reference 跑跑看，把「CNV 證據強度」誠實分級；證據弱的地方用佐證補（惡性細胞按腫瘤分島 vs 基質跨腫瘤混合、SyS 標記如 SS18-SSX 下游程式的表達），**每個佐證的邏輯與極限寫清楚**——這題就是要你體會單一判準失靈時怎麼組合證據。
3. 兩平台的惡性細胞數清點表：後面每個對照分析的可行性在這裡決定。

### 階段 B：核心程式與病人多樣性（B12、B19）

4. 病人內先做（B19）：對惡性細胞夠多的腫瘤逐一跑病人內分群或 NMF，提取程式基因清單；跨腫瘤比對（Jaccard／超幾何），找「多數腫瘤都出現的共同核心程式」與病人私有程式。原論文報過 SyS 的核心致癌程式——先自己做完再對答案，一致與不一致處都寫下來。
5. 同一組分析在**另一個平台**重做，程式層對照：共同核心程式兩邊都找得到嗎？私有程式呢？做一張「程式 × 平台」對照表——這是本題的主圖。
6. 深淺的解剖（呼應進階09）：挑出只有 SS2 找到的程式，檢查它的成員基因在 10x 裡的偵測率（是深度問題）還是根本不表達（是真差異）；反過來，10x 靠細胞數抓到的小群/稀有程式，SS2 的 n 撐得起來嗎？

### 階段 C：一個駕駛下的多樣性（發表導向）

7. 二選一深挖：**(a)** 病人私有程式的來源——它們與細胞品質、細胞週期、微環境組成（該腫瘤的免疫浸潤程度）哪個相關？排除技術假象後還剩下的「真多樣性」是什麼？**(b)** 微環境角度：SyS 是出名的免疫冷腫瘤（原論文主線之一是惡性程式與免疫排斥的關聯）——找它沒細看的格子，例如基質/內皮的亞型結構與跨腫瘤一致性。
8. 穩健性：換程式提取方法（分群 marker vs NMF）、去掉貢獻最大的腫瘤、兩平台各自重跑——只在一個平台一種方法出現的程式降級為候選。
9. 寫「發表路徑」評估（見下節，300–500 字）。

## 發表路徑

讀 `_從練習到投稿指南.md` 後回答：

- **訊號分類與穩健性**：你的核心程式/多樣性來源屬於指南第二節哪一類？雙平台本身就是內建的一層互驗——兩邊都成立的訊號才有資格談外部驗證；只在單平台出現的，先解釋為什麼。
- **驗證設計**：間葉腫瘤的方法互驗場是**進階34（骨肉瘤 GSE152048）**——它的「間葉 CNV 判定＋多重佐證」流程與你的階段 A 互為鏡像，兩題的判定策略可以互相壓力測試；融合蛋白癌的跨癌延伸（Ewing sarcoma、fusion+ rhabdomyosarcoma 等單細胞資料集）**自己上 GEO 查**，問核心程式是 SyS 私有還是「單一駕駛癌」的共相。
- **novelty 定位**：原論文已經把核心致癌程式、免疫排斥、與（藥物實驗中的）HDAC 抑制反應做成完整故事——重現不是發現。你的角度（平台深淺對程式發現的系統性影響？私有程式的來源分解？）用 PubMed 查（「synovial sarcoma single-cell」文獻不厚，這是少數藍海）；「雙平台程式可重現性」的方法學敘事本身有資源型論文的骨架。
- **缺什麼＋目標期刊層級**：缺獨立 SyS 隊列（罕見癌，可能真的沒有——這時跨融合蛋白癌的驗證是務實替代）與機制佐證；方法學角度扎實的話落在計算/組學期刊（Briefings、CSBJ 類），否則 Scientific Reports 層級，先掛 bioRxiv。

<details><summary>提示 3：程式對照的量化</summary>
