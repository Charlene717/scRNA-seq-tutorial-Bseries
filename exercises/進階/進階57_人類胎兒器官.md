# 進階 57 · 胎兒的器官、成人的對照：Descartes 圖譜再分析

**難度**：★★★ ｜ **預估時間**：2 個工作天 ｜ **對應集數**：B10、B11、B18、B19 ｜ **資料集**：GSE156793 Descartes 按器官 RDS（本題獨用）

## 背景與研究主題

Cao 等人（2020）的人類胎兒基因表達圖譜（Descartes）用 sci-RNA-seq3 測了約 400 萬顆細胞、121 個樣本、15 個器官——但你不需要 400 萬顆：官方站把圖譜**按器官切成一個個 RDS**（取樣子集共 377,456 顆；小器官如 thymus 只有 11 MB），這是「大圖譜的正確打開方式」的教材級示範。本題選 thymus（建議；也可再加一個小器官對照）：胎兒胸腺是 T 細胞發育的現場，從前驅細胞到成熟 T 細胞的整條生產線都擠在同一個器官裡，而你在 PBMC 題目裡認識的 T 細胞只是這條線的成品。這也是「圖譜再分析找被忽略角落」的實戰——原論文的主角是 15 器官鳥瞰，單一器官的細節就是留給你的空間。你的研究主題：

1. 胎兒 thymus 的型別組成：T 細胞發育的各站（早期前驅、DN/DP/SP 各階段、以及支持它們的胸腺上皮與基質）在這份資料裡抓得到幾站？
2. 胎兒 vs 成人：把胎兒 thymus 的 T 系細胞對到成人 PBMC 參考（進階58 的 pbmcref），哪些胎兒狀態在成人血液裡「沒有家」？這說明了什麼？
3. 被忽略的角落：非 T 的配角（胸腺上皮、基質、其他免疫細胞）有沒有跨樣本一致、但原論文沒展開的結構？

## 資料集

- **GSE156793 / Descartes 官方站**（sci-RNA-seq3；~4M cells／121 樣本／15 器官；官方取樣子集 377,456）。
- **本題指定用官方按器官 RDS，選 1–2 個小器官**（thymus 11 MB 為首選）：從 `descartes.brotmanbaty.org` 下載（免登入；檔名、版本與該器官細胞數以官方站為準，記進報告）。不要抓 GEO 全量矩陣；raw 在 dbGaP 管制，一律不用（資料集總覽明訂）。
- sci-RNA-seq3 淺測深廣：每細胞 UMI 偏低是平台常態，QC 與註解策略都要因此調整（見真實數據關卡）。

## 真實數據關卡

真實資料在你跑第一行 Seurat 之前就開始出題。這一節照做並記錄：

1. **官方站導航也是技能**：Descartes 站上同一份圖譜有多種切法與格式——先搞清楚你下載的是「按器官取樣 RDS」而不是別的產物，把下載頁的描述、檔名、日期抄進筆記。下載回來第一件事：`readRDS` 後印出物件的 class——它可能不是 Seurat（SingleCellExperiment／cds 一類；以物件為準），盤點表達矩陣的位置與尺度（counts？有無小數）、細胞註解欄（作者型別註解叫什麼、還有哪些樣本欄位）、基因 ID 是 symbol 還是 Ensembl（後者你需要一張轉換表才能用 marker）。
2. **淺測深廣的後果**：算這份資料的每細胞 UMI／基因數分布，跟你在基礎01 的 10x PBMC 並排。QC 閾值照抄 10x 慣例會發生什麼（一刀切掉大半細胞）？sci-RNA-seq3 的低深度靠什麼補（細胞數）？註解時單一 marker 的 dropout 會更兇——策略要從「看單一基因」改成「看基因組合／module score」。每個因此調整的參數寫三件事。
3. **取樣子集與樣本結構**：這是全圖譜的取樣，不是全部細胞。列出你的器官裡有幾個 donor／樣本、每樣本幾顆細胞（欄名以物件為準）——之後所有「組成比較」的統計單位是樣本，不是細胞。樣本間若有胎齡差異，它是干擾還是你可以利用的第二條軸？想清楚寫進日誌。
4. **決策日誌**：開 `decisions.md`，凡是「資料逼你做的決定」（下載版本、物件解剖發現、基因 ID 處理、QC 調整、樣本結構）都記一筆：發現了什麼 → 選項 → 你選了什麼 → 理由。這是繳交物，也是論文 Methods 的草稿。

## 提示（卡關再看）

<details><summary>提示 1：陌生 RDS 的解剖順序</summary>
`obj <- readRDS(...)` → `class(obj)` → 若是 SingleCellExperiment 系：`assayNames(obj)`、`colData(obj)`、`rowData(obj)`；轉 Seurat 可用 `as.Seurat` 或手動 `CreateSeuratObject(counts=...)` 再把 colData 塞進 meta.data。基因若是 Ensembl ID，用 rowData 裡現成的 symbol 欄（若有）或 biomaRt/annotables 轉換——轉換掉了多少基因、重複 symbol 怎麼處理，都是 decisions.md 的材料。
</details>

<details><summary>提示 2：低深度下的註解策略</summary>
單顆細胞的 CD4 讀不到不代表它不是 CD4 T——sci-RNA-seq3 深度下 dropout 是常態。用 `AddModuleScore` 把每站的 marker 清單打成分數、在 cluster 層級判讀（cluster 平均表達的 dotplot 比 feature plot 可靠）。發育中間態的界線本來就連續，「兩站之間」的 cluster 誠實標成過渡，不要硬塞。
</details>

<details><summary>提示 3：Azimuth 的最短路徑</summary>
R 裡 `Azimuth::RunAzimuth(query, reference="pbmcref")` 一行可跑（reference 首次會下載；版本記進筆記）。回傳物件帶 predicted labels 與 mapping/prediction scores。把「胎兒發育階段（你的註解）× 成人預測標籤」做成列聯表、附每格的中位 score——這張表就是階段 B 的核心產出。
</details>
