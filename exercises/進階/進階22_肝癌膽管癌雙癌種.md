# 進階 22 · 同一個器官、兩種癌：HCC vs iCCA

**難度**：★★★ ｜ **預估時間**：1.5–2 個工作天 ｜ **對應集數**：B11、B16、B19（肝癌戰法）｜ **資料集**：GSE125449（本題獨用）

## 背景與研究主題

肝臟會長出兩種主要的原發癌：肝細胞癌（HCC）與肝內膽管癌（iCCA）——同一個器官、不同的細胞起源、不同的臨床命運。Ma 等人（2019）用 10x 定序了 19 顆腫瘤（9 HCC + 10 iCCA），是「同器官雙癌種比較」的現成舞台。但這份資料以活檢為主，總共只有 9,946 顆細胞——分到每位病人，惡性細胞可能只有個位數到數十顆。**細胞數少不是缺陷，是活檢的誠實限制**；這一題一半在比較 HCC 與 iCCA，另一半在練習「小 n 之下哪些話能說、哪些話不能說」。你的研究主題：

1. HCC 與 iCCA 的惡性細胞程式差在哪？存在跨癌種共同的「肝癌程式」嗎？
2. 微環境（CAF、TAM、內皮…）的組成與狀態，跟著癌種走還是跟著病人走？
3. 每病人惡性細胞可能個位數——在這個 n 下，你的比較還剩多少統計正當性？

## 資料集

- **GSE125449**（10x 3' v2；9,946 cells＝Set1 5,115 + Set2 4,831；19 腫瘤：9 HCC + 10 iCCA）
- 格式：**10x 三件套 ×2 sets + samples.txt**（barcode 對病人/樣本的對照表）。
- 本題**不取子集**——全量本來就小；小，正是題目本身。

## 真實數據關卡

真實資料在你跑第一行 Seurat 之前就開始出題。照做並記錄：

1. **兩個 Set 的三件套分讀合併**：Set1、Set2 各是一組 matrix/barcodes/features——`Read10X` 分別讀、barcode 加 set 前綴再 `merge`。驗貨：兩物件的細胞數對得上 Set1 5,115／Set2 4,831 嗎？基因清單兩個 set 一致嗎（不一致怎麼辦，記錄）？尺度確認：三件套應是 raw counts——用整數性與分布佐證，別只是相信。
2. **samples.txt 解剖**：先用 `readLines(n=5)` 看清楚欄位再讀。哪一欄是病人？癌種標籤（HCC/iCCA）藏在哪一欄、什麼編碼（以檔案實況為準）？barcode 與矩陣欄名的格式對得起來嗎（有無後綴差異）？掛上 metadata 後，第一件事是做**每病人細胞數表**——這張表決定你整個分析計畫的天花板，先看清楚它再往下走。
3. **最低細胞數門檻**：惡性判定與程式比較都需要「每病人惡性細胞 ≥ 某個數」——門檻設多少（20？30？）、被門檻踢掉幾位病人、他們集中在哪個癌種？門檻是你訂的，數字、理由、紀錄，並在階段 C 做門檻敏感度檢查。
4. **決策日誌**：開 `decisions.md`，凡是「資料逼你做的決定」都記一筆：發現了什麼 → 選項 → 你選了什麼 → 理由。它是繳交物，也是論文 Methods 的草稿。

## 任務

### 階段 A：合併、整合與惡性判定（對應 B5–B11、B16）

1. 分讀合併、QC（肝組織粒線體比例天生偏高——閾值看這份資料自己的分布訂，同進階08 的提醒）。
2. **整合範圍決策**（B11/B19）：set 是技術批次、病人是病人、癌種是你要保留的生物訊號——校正做在哪一層？寫下決策與理由，並畫「校正前後」對照圖檢查癌種差異沒被整合抹掉。
3. 惡性判定：**惡性判定靠 CNV 不是 marker**——inferCNV 逐病人跑（免疫細胞當 reference）；細胞數太少跑不動的病人怎麼辦（合併跑？放棄該病人？），記錄。

### 階段 B：雙癌種比較（對應 B16、B19 肝癌戰法）

4. 惡性程式比較：**統計單位是 19 位病人，不是 9,946 顆細胞**——每病人惡性細胞做 pseudobulk，HCC vs iCCA 的差異在病人層級檢定；過門檻的病人各癌種剩幾位，誠實寫在圖上。
5. 找「跨癌種共同的肝癌程式」：兩個癌種都偏離正常肝的方向裡，交集是什麼？（沒有正常肝對照——這個限制怎麼繞、繞不繞得過去，寫下來。）
6. 微環境比較：各型別的組成佔比與狀態程式，按癌種、按病人分別看——哪些差異「以病人為單位」仍然成立？

### 階段 C：小 n 的誠實與角落（發表導向）

7. 二選一深挖：**(a)** 原論文主線是腫瘤細胞多樣性驅動微環境重編程——你反過來問：微環境的哪個亞群（CAF 或 TAM 擇一）在兩癌種間差最多？做亞型分析與跨病人一致性檢查。**(b)** 方法學路線——把「每病人惡性細胞數」對「該病人程式分數的穩定度」做系統分析：n 多小的時候結論開始翻覆？這是給所有活檢研究的量化警告。
8. 穩健性：改變最低細胞數門檻（±10）、去掉細胞數最多的病人、換整合方法，核心結論還在嗎？
9. 寫「發表路徑」評估（見下節）。

## 發表路徑

讀 `_從練習到投稿指南.md` 後回答：

- **訊號分類與穩健性**：你的 HCC/iCCA 差異屬於指南第二節哪一類？病人層級檢定後還顯著嗎——還是只剩 cell-level p 值在撐？門檻敏感度檢查的結果誠實嗎？
- **驗證設計**：HCC 那半邊，題庫內就有現成驗證場——**進階08 的 GSE149614**（HCC 大隊列、多部位、細胞數充足）與**進階09 的 GSE98638**（肝癌 T 細胞深測）——肝癌三部曲互驗：你在小 n 看到的 HCC 惡性程式或微環境訊號，去大隊列重現。iCCA 那半邊題庫內沒有第二個資料集——自己上 GEO 查候選並評估。bulk 層級：TCGA-LIHC 走進階10 的反卷積流程；TCGA-CHOL（膽管癌 cohort，樣本細節以 GDC 頁為準）自查。
- **novelty 定位**：HCC vs iCCA 的單細胞比較原論文已做主線——PubMed 查「HCC iCCA single-cell comparison」看後續還有誰做過什麼；你的角度（微環境亞群跨病人一致性？小 n 穩定度的方法學量化？）還剩多少新？
- **缺什麼＋目標期刊層級**：生物學路線缺大隊列驗證（進階08＋TCGA 補得上一部分）；方法學路線（小 n 穩定度）若做成系統模擬＋多資料集展示，可往 Briefings in Bioinformatics 層級；只有本資料集的觀察，落點是 Scientific Reports 層級或先掛 bioRxiv。

<details><summary>提示 1：samples.txt 掛 metadata</summary>
`read.delim` 後檢查 barcode 欄與 `colnames(seurat_obj)` 的格式差異（set 前綴、"-1" 後綴），`match()` 對齊再塞進 `meta.data`。掛完立刻 `table(patient, cancer_type)` 驗合理性——19 位病人、9+10 的分布對不對。

<details><summary>提示 2：病人層級比較</summary>
`AggregateExpression`（或自寫 rowsum）做每病人惡性細胞 pseudobulk → 程式打分或 DE 在這個 19×基因的矩陣上做。畫圖時每病人一個點、按癌種著色——審稿人要看的是點，不是雲。
</details>

<details><summary>提示 3：共同程式沒有正常對照怎麼辦</summary>
退而求其次的參照系：微環境中的非惡性肝實質細胞（若有）或兩癌種彼此互為對照（HCC 高於 iCCA 的、iCCA 高於 HCC 的、兩者皆高於微環境的）。每個選擇的偏誤寫進 decisions.md——這正是進階05「參照系設計」的肝癌版。
</details>
