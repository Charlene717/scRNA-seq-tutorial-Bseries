# 進階 34 · 不是上皮的癌：骨肉瘤三態勢

**難度**：★★★ ｜ **預估時間**：2–2.5 個工作天 ｜ **對應集數**：B11、B14、B16、B19 ｜ **資料集**：GSE152048（本題獨用）

## 背景與研究主題

到目前為止你判定過的惡性細胞幾乎都是上皮出身——骨肉瘤（osteosarcoma, OS）不一樣：它是**間葉來源**的兒童/青少年腫瘤，惡性細胞本身就是成骨系的親戚。這砸掉了你慣用的一根拐杖：inferCNV 拿 fibroblast 當 reference 在上皮癌裡很安全，在間葉腫瘤裡卻可能把惡性細胞的表親當成正常基準。Zhou 等人（2020）的資料集有 100,987 顆細胞、11 個病灶，罕見地涵蓋**三種疾病態勢：原發（65,895）、肺轉移（17,735）、復發（17,357）**；骨肉瘤自己的特色軸也全都在——成骨（osteoblastic）/軟骨（chondroblastic）分化、破骨細胞（osteoclast——myeloid 出身，不是惡性！）、以及高度浸潤的巨噬細胞。你的研究主題：

1. 間葉腫瘤的惡性判定要怎麼做才站得住？reference 選誰、錯選的後果多大？
2. 惡性細胞沿成骨/軟骨分化軸的分布，三種態勢（原發/肺轉移/復發）有沒有系統性差異？
3. 巨噬細胞與破骨細胞的區塊在三態勢間怎麼變？誰在跟惡性細胞喊話（B14）？

## 資料集

- **GSE152048**（10x，NovaSeq；100,987 cells：原發 65,895 + 肺轉移 17,735 + 復發 17,357；11 個病灶）
- 下載：GEO Supplementary files——**逐病人的 matrix.tar.gz，各自解開後是 10x MTX**；批次解壓讀入見真實數據關卡。
- 病灶的態勢（原發/肺轉移/復發）對應要自己從各 GSM 頁建表（以 GEO 頁為準）。
- 十萬顆細胞：**主分析照任務取子集**（建議 16–32 GB RAM）。

## 真實數據關卡

真實資料在你跑第一行 Seurat 之前就開始出題。照做並記錄：

1. **逐病人 tar.gz 批次解壓讀入**：每個病灶一個 `matrix.tar.gz`——先解一個看內部結構（資料夾層級？檔名是不是 `Read10X` 認得的標準三件套？）再寫批次迴圈：`untar` → 必要時改名 → `Read10X` → barcode 加病灶前綴 → 落地 rds。尺度雙重確認（整數 UMI？GEO 頁描述？）。一個樣本走通再跑全部，解壓的中間檔案記得清理（磁碟也是資源）。
2. **三態不平衡設計盤點**：建「病灶 × 態勢 × 細胞數」表——原發佔近三分之二，肺轉移與復發各只有一萬七千多顆、病灶數更少（以 GEO 頁為準）。開工前寫下：哪些比較的統計單位是病灶（n 個位數！）、哪些問題根本只能敘述不能檢定；細胞數多≠證據多，這張表貼在筆記開頭。
3. **間葉腫瘤的 CNV reference 危機**：這是本題最重要的一關。惡性判定靠 CNV 不是 marker——但 reference 不能再隨手選「非免疫的基質」：骨肉瘤裡的 MSC/fibroblast/成骨样細胞可能就是惡性群的親戚或其一部分。先寫下你的 reference 候選（免疫細胞是最安全的起點）與排除理由，並設計一個敏感度測試：換一組 reference 重跑，判定翻盤的細胞是誰。
4. **決策日誌**：開 `decisions.md`，凡是「資料逼你做的決定」（解壓整理、子集規則、reference 選擇）都記一筆：發現了什麼 → 選項 → 你選了什麼 → 理由。這是繳交物，也是論文 Methods 的草稿。

## 任務

### 階段 A：合併、註解與間葉惡性判定（B11、B16）

1. 完成真實數據關卡，取子集（規則自訂並記錄：三態病灶全保留、細胞數大的病灶 downsample 是合理起點）。整合範圍決策（B11）：11 個病灶、三種態勢、兩種器官位置（骨 vs 肺）——batch 用什麼單位？肺轉移檢體帶著肺的本底細胞，整合會不會把「器官差異」與「態勢差異」攪在一起？
2. 註解大類：成骨系（osteoblastic）、軟骨系（chondroblastic）、破骨細胞（CTSK、ACP5 方向——**myeloid 出身，先驗上不是惡性**）、TAM/單核球、T/NK/B、內皮、周細胞、MSC/fibroblast。破骨細胞是多核巨細胞，QC 指標的分布會很怪——別讓標準閾值把它們全砍了，決策記錄。
3. inferCNV 惡性判定：免疫細胞當 reference 起步，對成骨/軟骨/MSC 區塊判定；跑關卡 3 設計的 reference 敏感度測試，把「判定對 reference 的依賴度」量化寫出來。OS 的基因體以劇烈複雜的 CNV 出名——熱圖該很精彩，太乾淨反而要起疑。

### 階段 B：三態勢的解剖（B19）

4. 惡性細胞的分化軸：成骨/軟骨 signature 打分（清單來源記錄），每個病灶的惡性細胞攤在分化軸上，病灶內先看結構、再跨病灶比（B19 病人內先做原則）。同一病灶內是不是混合了成骨、軟骨兩型？
5. 三態比較（誠實版）：原發 vs 肺轉移 vs 復發的惡性程式差異——以病灶為單位做 pseudobulk，n 個位數的限制明寫；找的是「方向一致的候選」不是 p 值。器官本底的混淆（肺轉移的差異是轉移還是肺？）要正面討論。
6. 微環境三態：TAM、破骨細胞、T 細胞的組成與程式在三態間怎麼變？破骨細胞在肺轉移灶裡還有嗎（它的家在骨頭）？

### 階段 C：巨噬—腫瘤軸與發表導向（B14）

7. 巨噬細胞深挖＋通訊：TAM 亞型結構（跨病灶一致性檢查），接 B14 的通訊分析——TAM/破骨與惡性細胞之間的 L-R 訊號（RANKL–RANK 軸是教科書候選，資料裡看得到嗎？），三態勢之間通訊格局有沒有變？通訊結果照 B14 的批判性檢視原則過濾。
8. 穩健性：換 reference 重跑判定後結論還在嗎？去掉細胞數最大的病灶、換分化 signature 來源，三態的候選差異還在嗎？
9. 寫「發表路徑」評估（見下節，300–500 字）。

## 發表路徑

- **訊號分類與穩健性**：你的三態差異或 TAM 訊號屬於指南第二節哪一類？以病灶為單位 n 有多少、reference 敏感度過了沒——這兩關過不了的結論一律降級成「候選」。
- **驗證設計**：單細胞端的間葉方法互驗場是**進階21（神經母細胞瘤）**——同為兒科、非上皮腫瘤，它的「發育參照系＋投影」思路可反過來檢查你的分化軸打分；bulk 端接 **TARGET-OS**（美國兒癌基因體計畫的骨肉瘤隊列——**存取條件、資料層級自己查證**，處理後表達與臨床欄位通常可用），沿進階10 的流程問你的分化程式/TAM signature 與預後的關聯。
- **novelty 定位**：OS 單細胞在 2020 後已有數篇（PubMed 查「osteosarcoma single-cell」）——原論文自己就報了 TME 的免疫抑制格局；你的角度（三態勢的分化軸位移？reference 敏感度的方法學教訓？RANKL 軸的態勢差異）查完文獻還剩多少新？「間葉腫瘤 CNV 判定的系統性評估」本身可以是方法學短文的骨架。
- **缺什麼＋目標期刊層級**：缺獨立 OS 隊列驗證與機制佐證；三態 n 太小是硬傷，誠實的落點是計算/組學期刊（若方法學角度扎實）或 Scientific Reports 層級，先掛 bioRxiv。

## 提示（卡關再看）

<details><summary>提示 1：批次解壓的骨架</summary>
`tars <- list.files(pattern="tar.gz$")`；迴圈內 `untar(f, exdir=樣本資料夾)` → `list.files` 看實際層級 → 找到三件套所在的資料夾餵 `Read10X`。不同病灶的內部層級可能不一致——迴圈裡放防呆檢查（找不到 matrix.mtx 就報錯停下），別假設全部長一樣。
</details>

<details><summary>提示 2：惡性 vs 正常成骨系的拆法</summary>
CNV 是主判準，但可以加兩個佐證：惡性群通常病灶私有（正常 MSC/內皮跨病灶混得開，惡性細胞按病灶分島——B19 講過的現象在間葉腫瘤一樣成立）；增殖分數與經典 OS 標記（如 ALPL、RUNX2 高表達又帶 CNV）可以當旁證。三個證據方向一致才下結論，只靠一個都不行。
</details>

<details><summary>提示 3：RANKL 軸的查法</summary>
RANKL＝TNFSF11、RANK＝TNFRSF11A、護骨素 OPG＝TNFRSF11B。先用 FeaturePlot/DotPlot 徒手看這三個基因誰表達在哪個型別，再看通訊工具的輸出有沒有抓到同一件事——工具輸出與徒手檢查不一致時，相信徒手檢查並追查原因（B14 的批判性檢視原則）。
</details>
