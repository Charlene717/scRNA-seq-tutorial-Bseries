# 進階 45 · 同一個人的兩個戰場：鼻咽癌腫瘤-血液配對與 TCR 輕量版

**難度**：★★★ ｜ **預估時間**：2 個工作天 ｜ **對應集數**：B11、B12、B19 ｜ **資料集**：GSE162025（本題獨用）

## 背景與研究主題

「腫瘤浸潤 T 細胞跟血液裡的不一樣」是免疫腫瘤學的常識，但多數資料集只能拿別人的血當對照——病人間變異把訊號稀釋殆盡。Liu 等人的鼻咽癌（NPC）設計把對照做到最乾淨：**10 位病人，每位同時取腫瘤與外周血**（共 176,447 顆細胞），同一個人的血液就是他自己腫瘤的基線；再配上 **scTCR-seq**，clonotype 成為跨部位追蹤細胞的條碼——同一個 clone 在血裡是什麼狀態、進了腫瘤變成什麼狀態，第一次能配對著問。本題做 **TCR 輕量版**：不重建 clonal 網絡、不做 repertoire 統計全家桶，只用最有生物訊息的一招——**clonotype 大小 × 轉錄狀態**。你的研究主題：

1. 同病人配對下，腫瘤 vs 血液的免疫組成與 T 細胞狀態差在哪？哪些差異在 10 對（你取的子集內每一對）方向一致？
2. 擴張的 clonotype（大 clone）集中在哪些轉錄狀態？腫瘤裡的大 clone 在血裡找得到嗎、狀態一樣嗎？
3. 配對設計的統計紅利：同樣的比較，用「配對檢定」與「混起來比」結論差多少？

## 資料集

- **GSE162025**（10x + scTCR；176,447 cells；10 對 NPC 腫瘤-血液配對）。
- 格式：**RAW.tar 278.7 MB（逐樣本 CSV）＋ TCR CSV**，GEO Supplementary files 下載。
- 本題**務必取子集**（資料集總覽明訂）：建議取 **5 對病人**（腫瘤＋血液都要，配對不能拆）；選誰（細胞數？TCR 檔齊不齊？）、為什麼，記錄。
- 同癌種的另一個隊列 GSE150430 在**進階32**——它是本題現成的外部驗證場（見發表路徑）。

## 真實數據關卡

真實資料在你跑第一行 Seurat 之前就開始出題。照做並記錄：

1. **RAW.tar 的 CSV 批次讀入**：`tar -tf` 先列清單不解壓——多少檔？命名規則透露的樣本結構（病人 × 部位）跟「10 對」對得上嗎？TCR 檔跟表達矩陣檔怎麼配對？重建 GSM/檔名 → 病人 → 部位的對照表存成 csv。然後解壓你選的子集，先讀**一個**表達 CSV 看結構（基因在列還是欄？counts 還是處理過？用分布佐證），再寫批次迴圈：讀入 → 驗貨 → 轉稀疏 → 細胞名加樣本前綴 → 合併。
2. **TCR CSV 與表達矩陣的 barcode 對齊**：這是本題最陰的一關。TCR 檔的 barcode 格式（有沒有 `-1` 後綴？有沒有樣本前綴？）跟你合併後的細胞名多半**不完全一致**。先各抽 20 個 barcode 肉眼比對，寫轉換規則，然後量化對齊率：每個樣本有 TCR 資訊的細胞佔比多少？對齊率異常低的樣本，是規則錯了還是這個樣本本來就只測了部分？沒有 TCR 的細胞（非 T 細胞、掉線的 T 細胞）怎麼標記，決定並記錄。
3. **配對設計的統計單位**：本題的統計單位是「病人」，比較的單位是「同病人的腫瘤-血液差值」——任何跨部位比較，先做每病人一個值（比例、平均分數），再做配對檢定（n=5 對的 Wilcoxon signed-rank 極限在哪，誠實評估）。細胞層級 p 值在 17 萬顆細胞上必顯著、必不可信——這句話貼在螢幕上。
4. **決策日誌**：開 `decisions.md`，凡是「資料逼你做的決定」（子集選擇、讀檔結構、barcode 轉換規則與對齊率、統計單位）都記一筆：發現了什麼 → 選項 → 你選了什麼 → 理由。它是繳交物，也是論文 Methods 的草稿。

## 任務

### 階段 A：配對地景（B11、B12）

1. 子集批次讀入、合併、QC 到 UMAP。**整合範圍**決策（B11 ⑤+ 策略室）：腫瘤與血液是兩種組織環境、10 個樣本又各有批次——校正到哪一層（不校正／按病人／按樣本）？每個選項會把哪種真實差異一起抹掉？選定後設計事後檢查。
2. 免疫細胞註解（B12）：T/NK/B/myeloid 大區塊，再對 T 細胞做狀態精析（naive/memory/effector/exhausted/Treg——框架可沿用進階09）。
3. 配對組成比較：每病人算腫瘤 vs 血液的各型別/狀態比例，畫「配對線圖」（每病人一條線連兩個部位）——方向一致的變化與病人各自為政的變化，一眼分開。

### 階段 B：clonotype 大小 × 狀態（B12、B19）

4. TCR 對齊（照關卡 2 的規則），每顆 T 細胞標上 clonotype ID 與該 clone 的大小（該病人內的細胞數）。**clonotype 只在病人內有意義**——跨病人撞出相同 CDR3 的處理方式（極罕見但會發生）寫進 decisions.md。
5. 擴張 × 狀態：把 clone 大小分箱（singleton／小／大——切點自訂並記錄），比較各轉錄狀態的擴張程度。腫瘤裡的擴張 clone 集中在哪些狀態（exhausted？effector？）——這是「clonal 擴張的轉錄面孔」。
6. 跨部位追蹤：對每位病人，找**腫瘤與血液共享的 clonotype**——同一個 clone 在兩個部位的狀態組成一樣嗎？畫「clone 的雙城記」圖（共享 clone 的腫瘤端狀態 × 血液端狀態列聯）。血裡追得到的腫瘤大 clone 佔多少？追不到的呢——是真的不在血裡，還是採樣深度問題？兩種解釋怎麼區分，寫下來。

### 階段 C：被忽略的角落（發表導向）

7. 二選一深挖：**(a)** 血液端的「腫瘤印記」——血液 T 細胞裡能不能找到預測腫瘤端狀態的訊號（共享 clone 的血液端狀態有沒有特異程式）？液態活檢邏輯的單細胞版；**(b)** T 細胞之外——B/myeloid 區塊的腫瘤-血液配對差異，原論文聚焦什麼、繞開它找被輕描淡寫的訊號。
8. 穩健性：換 clone 大小切點、去掉細胞數最多的病人、換一組 5 對子集（如果磁碟允許，加讀 2 對換血）、狀態註解換 resolution，核心結論還在嗎？
9. 寫「發表路徑」評估（見下節）。

- **驗證設計**：現成外部驗證場就在題庫內——**進階32**（GSE150430，同癌種 47,866 cells、15 NPC＋1 正常鼻咽，不同隊列不同格式）：你的腫瘤端 T 細胞狀態結構與擴張狀態的轉錄面孔，在那個隊列重現嗎（它沒有配對血液與 TCR——哪些結論可驗、哪些不可，先劃清）？T 細胞狀態與治療反應的對照系是**進階04**（GSE120575 黑色素瘤免疫治療）——你在腫瘤端找到的擴張狀態，跟它的 responder/non-responder 訊號有沒有可比之處？

## 提示（卡關再看）

<details><summary>提示 1：tar 偵查與子集解壓</summary>
`tar -tf GSE162025_RAW.tar | head -50` 看命名規則；`tar -xf ... --wildcards "*GSMxxxxxxx*"` 只解你要的樣本。表達 CSV 用 `data.table::fread` 讀（dense csv 用 read.csv 會等到天荒地老），讀完立刻轉 `dgCMatrix` 落地 rds。
</details>

<details><summary>提示 2：barcode 對齊的轉換規則</summary>
常見差異：TCR 檔是 `AAACCTGAGxxxxx-1`、表達端被你加了前綴成 `P1_Tumor_AAACCTGAGxxxxx-1`，或其中一邊被去掉 `-1`。寫一個小函數把兩邊都正規化成「樣本ID＋裸 barcode」再 join。對齊率算完畫成每樣本的長條圖放進筆記——這張圖是審稿人問「TCR 資料品質」時的第一答。
</details>

<details><summary>提示 3：配對線圖與雙城記</summary>
組成比較用 `ggplot` 的 `geom_line(aes(group=patient))` + `geom_point`，x 軸兩檔（Blood/Tumor）——5 條線全同向就是最有力的圖。共享 clone 列聯：取該病人腫瘤與血液都 ≥2 顆細胞的 clone，行=血液端狀態、列=腫瘤端狀態，數字是 clone 數（不是細胞數——又是統計單位）。
</details>
